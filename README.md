# 政策情报台

聚合 8 个政府官网，保存标题、正文、原文链接、官网发布日期、首次收录时间与运行记录。支持关键词、网站、类别、发布日期和今日收录筛选；网站可在界面新增或暂停。

## 本地运行

- npm install
- npm run dev — 本地工作台，http://127.0.0.1:4174
- npm run crawl — 采集到本地 SQLite，输出 bootstrap 快照
- node scripts/digest.mjs — 用已登录 Codex CLI 整理本地简报
- npm test — 抓取、去重、搜索、持久化状态及访问校验测试
- npm run build — 生成 Cloudflare Worker 部署文件

需要 Node.js 24 或更新的兼容版本。线上数据库为 D1，本地用 node:sqlite。网站配置保存在数据库。部署说明位于 .openai/hosting.json，定时编排与恢复规则见 HARNESS.md。

数据口径：全文搜索只针对成功提取的正文；图片、视频、扫描 PDF 暂不 OCR，相关页面仅按官方标题索引并明确提示。每轮采集有限额，当前入口以外历史内容尚未全部覆盖。相同 URL 去重，不同官网转载同一内容仍分别保留出处。分类使用标题和栏目规则，不作为法律效力判断。

直接双击 HTML 无法访问数据库，请使用本地服务或线上工作台。

## 数据与隐私

仓库中的 `data/bootstrap.json` 是公开政府网页的演示快照。运行时产生的 SQLite 数据库、日志、环境变量和导出文件已由 `.gitignore` 排除。公开部署前请自行确认新增数据不包含公司资料、账号凭证或其他私人信息。
